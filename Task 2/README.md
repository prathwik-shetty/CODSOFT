# Task 2 – Tic-Tac-Toe 

This project implements an unbeatable Tic-Tac-Toe game where a human player competes against the computer.

The computer uses a decision-making approach based on the Minimax algorithm to always choose the best possible move.

---

## Features
- Human vs Computer gameplay
- Unbeatable AI opponent
- Simple and clean Java Swing interface
- Real-time move evaluation

---

## Technologies Used
- Java
- Java Swing
- Basic AI (Minimax algorithm)

---

## How to Run
1. Open the project in any Java IDE (IntelliJ / Eclipse)
2. Run the `TicTacToeAI.java` file
3. Play as **X**, Computer plays as **O**

---

## Outcome
The human player can either draw or lose. The AI cannot be defeated.
